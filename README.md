# 🏦 Sistema Bancário em Java - JAMES BANK

Um sistema bancário orientado a objetos desenvolvido em Java, simulando operações essenciais de uma conta bancária, como depósitos, saques e exibição de dados/extrato com suporte a interação via menu no console.

---

## 📌 Funcionalidades

- **Cadastro de Cliente e Conta**: Associação de titular (Nome, CPF e Telefone) com dados da conta (Agência e Saldo).
- **Depósito Bancário**: Adição de valores ao saldo da conta.
- **Saque Bancário**: Retirada de valores do saldo.
- **Exibição de Extrato e Dados**: Impressão detalhada das informações do cliente e resumo do saldo.
- **Menu Interativo (Looping)**: Interface de terminal contínua utilizando `Scanner` e `switch-case`.

## 🚀 Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Jamesson-Alberto-Dev/Sistema-bancario-java.git
   ```

2. **Abra o projeto na sua IDE preferida** (Eclipse, VS Code, IntelliJ).

3. **Execute a classe principal:**
   Navegue até `src/JamesBank/Main.java` e rode o projeto (`Run`).
